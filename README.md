- Adjacency List

- Recursive DFS
- Iterative BFS

## Applications
- Network Traversal
- Path Finding
- Social Network Analysis

#  Practical 02 – A* Search Algorithm

## Aim
Implement the A* Search Algorithm for solving game search or pathfinding problems.

## Evaluation Function

\[
f(n) = g(n) + h(n)
\]

Where:
- `g(n)` → Actual path cost
- `h(n)` → Heuristic estimate
- `f(n)` → Total estimated cost

## Applications
- Game AI
- GPS Navigation
- Robotics
- Maze Solving
